# Webinar Funnel Demo

A single-file demo landing page in the "course seller" / webinar-registration
style — countdown bar, hero with video preview, pain points, curriculum
breakdown, opt-in form, testimonials, and a branded 3D-spin loading transition.

## Files

- `index.html` — the entire page (HTML/CSS/JS, no build step, no dependencies
  besides Google Fonts). Open it directly in a browser, or enable GitHub Pages
  on this repo to host it live.

## Notes

- All copy, names, and stats (registrant counts, testimonials, etc.) are
  placeholders for demo purposes — see the disclaimer in the page footer.
- Responsive: single-column layout under ~900px, wider two-column layout
  above that.
